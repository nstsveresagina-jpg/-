# Карусель «Да / Но» про Корею (JEJU TRIP)

7 слайдов 1080×1350 (`slide_1.png` … `slide_7.png`) по присланному примеру про Шри-Ланку, в стиле JEJU TRIP: каждый слайд — два фото друг над другом, оранжевая плашка «ДА» и кремовая «НО» (Advaken Sans), текст Comfortaa в полупрозрачной тёмной плашке, логотип сверху, нумерация. Последний слайд — призыв на тур «Сакура от Чеджу до Сеула» (без цены). Подпись к посту — `caption.txt`.
Фото: Pinterest, права у авторов. Пересборка: шрифты из `../brand-fonts` в `fonts/`, затем `NODE_PATH=$(npm root -g) node render.js`.
