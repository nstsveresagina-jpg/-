# Сторис «Фольклорные деревни Чеджу» (JEJU TRIP)

3 видео-сторис 1080×1920, по 10 с, без звука (`story_1.mp4` … `story_3.mp4`). Шаблон как у `../jeju-nov7-stories`: видео сверху, кремовая карточка снизу (Advaken Sans + Comfortaa), логотип, полоски прогресса; на последней — кнопка «Хотите с нами? Пишите в Direct».
Видео: Google Drive, папка от 8 ноября (20261108_102205, _100440, _100225).
Пересборка: исходники в `src/`, шрифты в `fonts/`, затем `NODE_PATH=$(npm root -g) node render_ov.js && python3 build_video.py`.
