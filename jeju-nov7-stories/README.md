7 видео-сторис 1080×1920 (`story_1.mp4` … `story_7.mp4`, 8–11 с, без звука) и статичные версии (`story_N.png`) по шаблону `korea-reviews-stories` из архива: фото сверху, кремовая карточка снизу, логотип в плашке, полароид, прогресс-полоски. Шрифты Advaken Sans + Comfortaa Light. Верх 250 px и низ 300 px свободны под интерфейс сторис.

## Видео-сторис
Сверху ролики с Диска (сад бонсай, водопад, яхта, закат), где видео нет — фото с медленным наездом; карточка и полароид — прозрачный оверлей `ov/ov_N.png`. Монтажный лист — `STORIES` в `build_video.py`.
Пересборка: `NODE_PATH=$(npm root -g) node render_ov.js && python3 build_video.py` (исходные видео в `src/`).
